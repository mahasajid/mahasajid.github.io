**September 2023 – December 2023**

Proposed and prototyped an automated baggage-management system for aviation using **barcode scanning, blockchain, and a relational database**. The project explored how blockchain could improve transparency and data integrity without sacrificing the performance benefits of conventional database systems.

I developed the concept as a research-paper proposal and prototyped a **hybrid blockchain + RDBMS architecture** designed to balance security, traceability, and system performance.

**Areas:** Blockchain · Database Systems · Security · Systems Design · Aviation Technology
